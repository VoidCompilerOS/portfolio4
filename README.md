# Ishu Gautam — Personal Portfolio & Data Analyst Showcase

Modern, responsive developer and aspiring Data Analyst portfolio built with vanilla HTML5, CSS3 glassmorphism, dynamic Canvas background animations, interactive Resume & Qualifications preview, and EmailJS integration.

## 🛠️ Features  & Tech Stack
- **Languages & Frameworks**: HTML5 Semantic Markup, Modern CSS3 with Custom Design System & Glassmorphism, Vanilla ES6+ JavaScript.
- **Interactive Resume Section**: Document frame with toggleable high-resolution preview and embedded PDF viewer, downloadable official resume, and ATS recruiter digest.
- **Data Pipeline Particle Visual**: Custom HTML5 Canvas rendering animated analytical data streams.
- **Dark & Light Mode**: Seamless theme toggle conforming to system preferences.
- **Verified Credentials**: Google Cloud Generative AI and Simplilearn certifications.
